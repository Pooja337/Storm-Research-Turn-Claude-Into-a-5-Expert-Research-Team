# Storm Research — Turn Claude Into a 5-Expert Research Team

Storm Research is a Claude Code skill inspired by Stanford’s STORM research methodology. It transforms a single research question into a structured multi-agent research process by using five expert research perspectives to investigate a topic, gather information, compare findings, identify contradictions, and produce a detailed final report.

The project demonstrates how to design and build a custom Claude Code skill from scratch, including the skill architecture, research workflow, expert roles, prompts, `SKILL.md`, and professional HTML report template.

### Key Features

* Uses a 5-expert research team approach.
* Performs structured, multi-perspective research.
* Explores different viewpoints and compares findings.
* Identifies contradictions and gaps in the research.
* Generates a professional, print-friendly HTML report.
* Includes a custom `SKILL.md` for Claude Code.
* Includes a reusable HTML report template.
* Supports self-critique and refinement of the final report.
* Provides an end-to-end automated research workflow.

### Workflow

1. Understand the STORM research methodology.
2. Design the Claude Code skill architecture.
3. Create the `SKILL.md` skill file.
4. Design the professional HTML report format.
5. Create the report template.
6. Review and improve the report design.
7. Run the Storm Research skill on a chosen topic.
8. Generate and review the final research report.

### Example Research Topic

**AI Voice Agents Replacing Customer Support Jobs**

The goal of this project is to demonstrate how Claude can be structured into a specialized research team that produces deeper, more organized, and professionally presented research from a single topic.
